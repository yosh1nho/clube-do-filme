Architecture · Clube do Filme

Quinzena — arquitetura em produção

Um clube de cinema entre 3 amigos: a cada quinzena um filme é escolhido, assistido, avaliado e ranqueado — com automação discreta da abertura até a promoção da próxima rodada.

Quem usa

3 membros, 3 dispositivos

  • SPA em HTML · CSS · JS puro, sem framework
  • Login por e-mail e JWT via Supabase Auth
  • Vistas: quinzena, ranking, histórico, explorar

Plataforma

Um app fim a fim

  • API Express · Node · 7 rotas REST
  • TMDB: busca, detalhes, pôsteres e sugestões
  • PostgreSQL: quinzenas, filmes, avaliações, reações

Automação

Quinzenas se viram sozinhas

  • Vercel Cron 03:05 UTC encerra as expiradas
  • Triggers no Postgres definem status e datas
  • pg_cron promove a próxima AGUARDANDO
